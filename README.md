# MORTI///STYLE — فروشگاه آنلاین (وب + اپ)

فروشگاه کامل لباس، کفش، ساعت، عینک، کمربند، کیف و ... با پنل مدیر. بدون نیاز به سرور و نصب؛ فقط HTML/CSS/JS.
A complete fashion shop with admin panel. Pure HTML/CSS/JS, no build step.

## اجرا روی کامپیوتر / Run locally
پوشه را باز کنید و `index.html` را در مرورگر باز کنید. یا:

```
cd morti-style-shop
python3 -m http.server 8080
# سپس باز کنید: http://localhost:8080
```

## پنل مدیر / Admin
- آدرس: `index.html#/admin` (یا لینک «Admin» پایین صفحه)
- رمز آزمایشی: `morti2026` (حتماً در Settings عوض کنید)
- در پنل: محصولات، دسته‌ها، برندها، سفارش‌ها، تنظیمات، پشتیبان‌گیری
- عکس محصول: دکمه «گرفتن عکس» (دوربین گوشی) یا «انتخاب از گالری» (چند عکس همزمان). عکس‌ها خودکار کوچک و فشرده می‌شوند.
- ترتیب عکس‌ها را با فلش‌ها عوض کنید و عکس اصلی را انتخاب کنید.

## پرداخت آزمایشی / Test payment
- کارت موفق: `4242 4242 4242 4242`، هر تاریخ آینده، هر CVC
- کارت ردشده: `4000 0000 0000 0002`
- شماره کارت ذخیره نمی‌شود (فقط ۴ رقم آخر در سفارش).

## معرفی روی GitHub Pages (رایگان) / Publish on GitHub Pages
1. در github.com یک ریپازیتوری جدید بسازید (مثلاً `morti-style`).
2. همهٔ فایل‌های این پوشه را آپلود کنید (Add file → Upload files).
3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / root → Save.
4. بعد از ۱–۲ دقیقه آدرس `https://USERNAME.github.io/morti-style/` آماده است.

جایگزین‌های ساده‌تر و رایگان (بدون نیاز به GitHub):
- **Cloudflare Pages** یا **Netlify Drop** (فقط پوشه را بکشید و رها کنید). سریع‌تر هستند و دامنه شخصی راحت وصل می‌شود.

## مهم: محدودیت نسخهٔ فعلی / Important
این نسخه «نمایشی» است: داده‌ها (محصولات، سفارش‌ها، عکس‌ها) فقط در **مرورگر همان دستگاه** ذخیره می‌شوند.
- مشتری‌های دیگر تغییراتی که شما در پنل مدیر می‌دهید را نمی‌بینند.
- رمز مدیر داخل مرورگر است و امنیت واقعی ندارد.
- پرداخت واقعی وصل نیست.

برای فروش واقعی لازم است:
1. **بک‌اند و دیتابیس مشترک:** مثلاً **Supabase** یا **Firebase** (محصولات، عکس‌ها، سفارش‌ها، ورود امن مدیر).
2. **پرداخت واقعی:** **Stripe** (کارت/Apple Pay/Google Pay) و PayPal.
3. **موارد قانونی در آلمان:** Impressum، Datenschutzerklärung، AGB، حق انصراف ۱۴ روزه، مالیات (USt).
   متن صفحات قانونی را در Admin → Settings می‌توانید بنویسید.

## اپ روی گوشی / As an app
سایت واکنش‌گرا است و فایل `manifest.webmanifest` دارد: در Safari/Chrome گزینهٔ «Add to Home Screen» را بزنید.
برای انتشار در App Store / Google Play می‌توان همین کد را با **Capacitor** به اپ تبدیل کرد.

## ساختار پوشه / Structure
```
index.html          صفحه اصلی (هر صفحه با hash مثل #/c/watches)
css/style.css       ظاهر
js/i18n.js          ترجمه‌ها (فارسی، آلمانی، انگلیسی)
js/store.js         داده‌ها و ذخیره‌سازی
js/icons.js         لوگو، آیکن‌ها، فشرده‌سازی عکس
js/app.js           فروشگاه (صفحه‌ها، سبد، پرداخت)
js/admin.js         پنل مدیر
```
